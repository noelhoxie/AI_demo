# App — Dashboard and UI assets

This folder contains all application assets for the Supply Chain Control Tower:

| Directory | Description |
|-----------|-------------|
| **novelis_dashboard** | OEE-focused dashboard (Novelis-style). Deployed as a Databricks app. |
| **databricks-flask-app** | Minimal Databricks + Flask example app. |
| **AI_App** | AI/demo app (templates and static assets). |

Deploy via the Databricks bundle: `databricks bundle deploy -t dev`.
